Windows Defender

Since we use VMProtect and Code Virtualizer

Our launcher file might be marked as a trojan by the windows defender, hence we advice to add your disks to exclusions, so the windows defender doesnt remove the launcher file.

DO NOT MAKE CHANGES TO WINDOWS DEFENDER UNLESS NECESSARY AND INSTRUCTED BY SUPPORT

Instruction via PowerShell

  1. Open powershell as Administrator
  2. Copy and paste the command, but change the drive name to the drive that your launcher is installed at (Usually C Drive)
Add-MpPreference -ExclusionPath 'C:\'

Adding disks to exclusions manually

  1. Open windows defender settings.
  2. Go to Virus & Threat protection.
  3. Press Manage Settings under Virus & threat protection settings
  4. Scroll to the bottom and find Exclusions settings, press Add or remove exclusions.
  5. In the opened tab press Add an exclusion, then select Folder
  6. Now go to This pc and select your disk where the launcher is installed

BIOS Mode

NON-UEFI BIOS Mode prevents our solutions from launching, so please make sure it is UEFI.

To find out the BIOS mode do this:

  1. Open msinfo32, by typing msinfo32 in windows search.
  2. Go to System Summary.
  3. Find line called BIOS Mode, if its UEFI, then you are good to go

If your BIOS Mode is UEFI, then go to the next page.

Virtualization

Introduction

Virtualization is required to run our solutions

  1. Open msinfo32, by typing msinfo32 in windows search.
  2. Go to System Summary.
  3. Find line called Hyper-V - Virtualization or Virtual Based Security Enabled in Firmware, if it says Yes, then you are good to go

Enabling virtualization

Enabling virtualization on AMD

  1. Open advanced settings.
  2. Open the Advanced section
  3. Locate the SVM Mode option
  4. Set the value to ENABLED
  5. Save your BIOS settings and restart your PC

Enabling virtualization on INTEL

  1. Open advanced settings.
  2. Open the Advanced section
  3. Locate the INTEL VIRTUALIZATION TECHNOLOGY option
  4. Set the value to ENABLED
  5. Save your BIOS settings and restart your PC

Fast Boot & Hibernation

Introduction

Fast Boot & Hibernation is required to be off by our product. The reason why is:

  1. With Fast Boot off system will start with a full reset RAM, guaranteeing that the product will load safely & completely.
  2. Hibernation being off drastically lowers the risk of product loading incorrectly.

How to disable Hibernation & Fast Boot

  1. Right-click the Start menu and select Windows Terminal (Admin).
  2. In Windows Terminal, enter the following command to turn hibernation off, then press Enter.
    powercfg /h off

How to download & run

First steps, making sure everything is correct

Before launching our solutions confirm this:

  1. Your secure boot is off.
  2. Your virtualization is on.
  3. Your BIOS Mode is UEFI.
  4. Your Fast Boot & Hibernation is off.

If you have confirmed that everything is right, then you may continue.
